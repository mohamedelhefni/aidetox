# Day 6 — Binary Search Tree

**Timebox:** 90 minutes  
**Files:** `pkg/bst/bst.go`, `pkg/bst/bst_test.go`

Implement `Insert`, `Search`, `Delete`, `Min`, `Max`, `InOrder`, `PreOrder`, and `PostOrder`. Preserve `left < node < right`; explicitly decide how duplicate values behave.

Test empty/degenerate/balanced shapes and deletion with zero, one, and two children—including deleting the root. Check that in-order traversal remains sorted after every mutation.
