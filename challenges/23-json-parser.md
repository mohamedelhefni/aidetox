# Day 23 — JSON Parser

**Timebox:** 2 hours  
**Files:** `pkg/jsonparser/parser.go`, `pkg/jsonparser/parser_test.go`

Do not use `encoding/json` for parsing. Start with objects containing strings, numbers, and booleans; if time remains add arrays, null, nested objects, and escape sequences.

Write down the subset you promise before coding. Test whitespace, empty containers, nesting, malformed separators, invalid literals/numbers, escapes you support, trailing input, and useful error positions. Stop at the timebox even if the full JSON standard is unfinished.
